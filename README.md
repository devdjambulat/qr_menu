# QR Menu Telegram Bot

📋 Полностью функциональный Telegram-бот QR-меню на Python + Aiogram 3 + SQLite.

Бот позволяет:
- Просматривать меню  
- Вызвать официанта  
- Сделать заказ  
- Оплатить через реквизиты  
- Администрировать меню и группы официантов  

---

## ⚙️ Функции

### Для пользователей:
- 📋 Меню — просмотр всех блюд  
- 🛎 Вызвать официанта — уведомление для подключённых групп  
- 🛍 Сделать заказ — (будет реализовано)  
- 💳 Оплатить — показывает реквизиты оплаты  

### Для администраторов:
- `/add` — добавить новое блюдо (фото, название, описание, цена)  
- `/edit` — редактировать существующие блюда  
- `/settings` — изменить реквизиты оплаты  
- `/group` — создать группу официантов  

> Админские команды работают только для ID, указанных в `ADMIN_IDS`.
